# Como Contribuir

Agradecemos seu interesse em contribuir com este projeto! Siga as instruções abaixo.

## Diretrizes de Codificação

Este projeto segue as diretrizes definidas em [AGENTS.md](AGENTS.md). Leia com atenção antes de enviar alterações.

## Fluxo de Trabalho

1. **Fork** o repositório.
2. Crie uma branch: `git checkout -b feat/sua-feature`.
3. Faça suas alterações e commit com mensagens descritivas.
4. Envie para sua branch: `git push origin feat/sua-feature`.
5. Abra um **Pull Request** descrevendo as mudanças.

## Commits

Siga o Convention Commits:

- `feat:` nova funcionalidade
- `fix:` correção de bug
- `refactor:` refatoração
- `test:` testes
- `docs:` documentação

## Testes

Antes de enviar seu PR, certifique-se de que todos os testes passam:

```bash
pytest tests/ -v
```

## Dúvidas

Abra uma issue para discussions e perguntas.
